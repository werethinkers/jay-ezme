# KeyDo 4.54

**Collections grid: videos no longer overlap**
- Every tile is now exactly the same size, with the same gap on all sides. The columns are worked out from the window width, so tiles line up when you sort or switch tabs, and when you resize the window.
- Video and GIF previews now show a still picture, and play only while your pointer is on that tile. A playing video can no longer draw over its neighbours, and the grid is lighter on memory.

**Keyboard safety:** checked. The key tap, popup, voice and every mode that swallows keys are untouched.
