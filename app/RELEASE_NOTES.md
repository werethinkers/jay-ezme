## MyDatabase: make shortcuts and bulk rename

- Make shortcuts: one click turns the ticked rows (or the whole list if none are ticked) into shortcuts. The collection name is filled in (Contacts, Links, Files or the table name) and you can change it once for all rows. You can also add a prefix and a suffix to every code and see a preview first.
- Contacts become shortcuts such as name, mobile and email, using the same code styles as Collection Builder. Links and files use their name as the code and their address or path as the text. Tables let you pick the name column and the columns to turn into shortcuts.
- Bulk rename: add a prefix or suffix, replace a prefix or suffix, find and replace, change the case, or turn spaces into hyphens for all ticked rows. For saved files you can choose to rename the real files on your Mac too. Extensions stay the same.
