# KeyDo 3.66

- **Fixed text is never asked for.** In App Designer a text box now has "Typed each time" or "Fixed words". Fixed words are printed as written and the app never asks for them; typed-each-time boxes are the ones the app asks for.
- **Every function in one place, grouped.** All Function menus (the designer's Add a box, the box editor and the wizard) now list Date and time, Where you are (city, place, area, place name, state, country, coordinates), Weather and sky, and Money and more (dollar and euro rates, Bitcoin, quote of the day). The function search panel has category chips and shows the place and live functions first.
- **Friendlier Add a box.** Collection, subcategory, default shortcut and variable cards now stack vertically instead of running wide, so they fit the side panel.
- **Library section removed** from the designer: picking a subcategory in Add a box does the same job.
