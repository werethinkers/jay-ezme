# KeyDo 4.53

**Collections grid: no more overlapping tiles**
- Sorting, or switching between Video, Image and the other type tabs, now rebuilds the grid cleanly. Every tile has the same fixed size, and video and GIF previews are clipped to their tile, so nothing overlaps.

**Hide or show the categories panel**
- A new sidebar button at the top left of a collection hides or shows the categories list, so the grid can use the full width. KeyDo remembers your choice.

**A neater Collections view**
- Roomier header and spacing, Favourites and Sort together in one row, softer card borders and corners, and a single-line tag strip so tiles stay even.

**Keyboard safety:** checked. The key tap, popup, voice and every mode that swallows keys are untouched.
