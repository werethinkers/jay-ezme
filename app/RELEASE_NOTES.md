## Prompt Builder: voice that hears # @ =, numbered suggestions, and "enter chatgpt" fixed up

- **Hears the marks properly.** Say "hash", "hashtag", "at sign", "mention", "equals", "equal sign" or "equal to"; if the Mac writes "#", "@" or "=" itself, that works too. Names are matched loosely: "hash rohit media" finds #rohit.media, "hash thumbs up" finds #thumbs-up, "equals today's date" gives =date. The speech engine is now told your shortcut names, people and these command words in advance, so it hears them far better.
- **Keeps listening.** One press of Speak now keeps listening, so you can dictate, run a command and say "enter chatgpt" without pressing again. A "Heard:" line shows what the Mac understood.
- **macOS dictation too.** The new **macOS dictation** button uses the Mac's own keyboard dictation. The command words ("hashtag", "equals date", "enter chatgpt") are still understood in what it types.
- **Forgot the mark? You get suggestions.** Plain words that match a shortcut, collection record, person or app (and "current date") are listed with numbers: click one, or say "accept suggestion 1", "accept all" or "dismiss suggestions".
- **"Enter ChatGPT" is more forgiving.** "Enter chat GPT", "enter chatgbt", "enter cloud" (Claude), "enter rock" (Grok) and similar mishearings now work, the site's button lights up green, and the prompt opens in the side panel and is sent.
- **Fixes from a review:** typing no longer lags while you speak (the live prompt updates a moment after you stop), a Polish with AI answer that arrives after you changed the prompt is no longer used by mistake, and an empty prompt now says so instead of silently sending nothing. The shortcut menus sit on their own row so they no longer squeeze.
