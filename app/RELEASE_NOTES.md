# KeyDo 3.78

- **Popup trigger:** the KeyDo popup now opens only from the backslash key (\) or by voice. The slash (/), the vertical bar (|) and the question mark (?) no longer open it, so they stop clashing with other apps. Shortcuts you type still start with a backslash.
- **Prompt Builder, prompt now reaches the site:** KeyDo now pastes the prompt into the site's prompt box as a real paste, which is what ChatGPT, Claude, Gemini and most image or video sites need before their Send button turns on. Before, the words could appear in the box while the site still saw an empty prompt, so only the media went through. Media, prompt and Send now run in that order, and the prompt is checked again after the media is added.
- Keyboard safety: this release only makes the key watcher accept fewer keys (backslash only). The 3.76 protections are unchanged; nothing new swallows keys.
