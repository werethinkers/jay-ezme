# KeyDo 3.92

## AppDesigner: the prompt for ChatGPT or Gemini has no placeholders
- The prompt no longer contains {{names}}, variable names, function or collection names, or starting values. Nothing about how your app is built is shared.
- It now says only that the blank areas are empty on purpose and must stay empty, listing each as "Blank text area 1" or "Blank picture area 2" with its place and size. The pictures sent already had the sample words removed.
- Fixed text, logos and icons are still kept as they are.

## Keyboard safety
Checked: this version only changes the wording of one prompt. The key tap, its release guard and the heartbeat watchdog were not touched.
