# KeyDo 4.08

## Update window is no longer cut off
The window that opens from "Check for updates" now has one fixed, larger size (560 x 480). It stays the same while checking, showing the notes, downloading and installing, so the notes and the Later / Update now buttons are always fully visible. The notes area scrolls inside it.

## Keyboard safety
Checked. Nothing in the key tap, popup, voice or key-swallowing modes was touched.
