# KeyDo 3.64

- **Type the app name and it runs.** An App Designer app now runs as soon as you type its name and press Return in the backslash popup. Variables are optional: an empty box uses the last value or its ready value, or is simply left out. Only a box marked Mandatory can stop it.
- **Better location.** CITY, PLACE and the new AREA and PLACENAME now use this Mac's own location when you allow it (the first time an app uses a place word, macOS asks once), so you get the neighbourhood and spot name, not just the city. If you say no, or it is not available, KeyDo falls back to the city from your internet address. Weather, sunrise and the rest follow the same location.
- **Add a box inside the designer, like in the New App wizard.** A new "Add a box" section at the top of the designer's side panel: say or type "two variables string and date, one picture", or tap Variable, Collection, Function, Picture or Text. Each opens the same card as the wizard (data type, ready value, subcategory and default shortcut, fixed text or media, mandatory) with an "Add to page" button.
