# KeyDo 4.56

**Research capture now downloads the real picture**
- When you copy a picture in the browser and the browser puts only its web address on the clipboard, KeyDo now downloads the picture file from that address. Before, nothing but a link was left.
- The file is saved in Pictures > KeyDo Research, so you can see and use it like any download, and it is listed in My Files (Media tab, collection Research) with the page address in its notes. The picture's own address is kept in the notes too.
- Only real pictures are saved. Links to pages, videos and other files are ignored, and a picture you already saved is not saved twice.
- Research capture never creates a shortcut.

**Keyboard safety:** checked. The key tap, popup, voice and every mode that swallows keys are untouched.
