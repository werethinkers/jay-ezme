## \reply: write a business reply from a copied message

- **Copy a message** (an email, a chat, a review, an enquiry), then type **\reply** and press Space. KeyDo writes the reply and pastes it in place of the command. It needs an API key, like \r.
- **Pick a style** by adding it after the command: `\reply-short`, `\reply-warm`, `\reply-firm`, `\reply-sales`, `\reply-support`, `\reply-sorry`, `\reply-no` (polite decline), `\reply-followup`, `\reply-thanks`. Plain `\reply` is a professional reply.
- The reply answers every question in the message, uses only facts from it, and puts missing details in [square brackets] for you to fill in. It is written in the same language as the message.
