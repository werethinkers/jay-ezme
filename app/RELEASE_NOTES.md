## AppDesigner: pictures and voice in the popup, and web pages for countdowns

- **Pictures work in the backslash popup.** A picture box of an AppDesigner app now has a box you can type a media shortcut name into, a list of matching media to tap, and an **Add image** button to pick a file from your Mac. Left empty, the app uses the last picture or the template's own, so it never stops to ask.
- **Fill the popup by voice.** A Speak button sits next to "Open the full form". Say a box name and its value ("name Rahul, photo ss10"). If you say a media shortcut KeyDo knows, the picture is filled; if not, it tells you and offers Add image. The popup form now always shows its boxes for design apps, and what you type there is what gets made.
- **Countdowns default to a web page.** When a design uses something that changes by the day or minute (days to go, COUNTDOWN, NOW, TIME), its output now defaults to HTML, and the page works out the number again every time it is opened, so it is never stale. Designs without such functions stay as an image (PDF for several pages). If you pick a format yourself in AppDesigner, your choice is kept.
- "Save the date with countdown" and "Festival countdown story" are now web pages with a live count.
