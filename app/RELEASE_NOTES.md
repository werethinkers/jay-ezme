# KeyDo 3.65

- **Prompt Builder sends the prompt and the media together on sites like SeaArt.** Some sites show their upload box before the prompt box has loaded, so KeyDo used to attach the media and miss the prompt. It now waits for the prompt box, falls back to finding any large text box on the page (so new sites work without setup), checks that the prompt is really in the box, and types it again if the site cleared it when the media went in. If a page will not take the prompt at all, the prompt is copied so one paste finishes the job.
- **One dictation input.** The second "macOS dictation" button is gone. Speak is the one mic, with all the command words.
- **Pronouns and small words no longer turn into shortcuts.** Words like I, me, my, he, she, her, him, his, they, the, and, that and similar are never marked as a shortcut by themselves, and punctuation-only keys are ignored, so dictation no longer attaches the wrong media or collection by accident. Use # or @ to pick one of those on purpose.
