## AppDesigner: voice that targets boxes, one panel, data types and spoken formulas

- **Voice commands now work on the box you name.** Say "make the name red", "title font Georgia", "amount bold", "background of the heading yellow" or "change title to Happy Birthday" and that box is selected and changed, like in Wish Builder. If a box holds a variable, "change name to Rahul" sets the variable's starting value. More colours were added (coral, saffron, burgundy, dark red, light green and more), and colour words are matched as whole words.
- **One panel.** Box, Library and Page now sit in a single scrolling panel with fold-open sections, so nothing is hidden behind a tab. Selecting a box opens its section.
- **Easier dropdowns.** Category, subcategory, field and font are now type-to-find lists. Functions have a searchable list with what each one does.
- **Data types for variables.** Give each variable a type: text, long text, number, whole number, currency, date, time, phone, email or web link (menu on the variable, or say "variable amount type currency"). The form, the live preview and the backslash popup check the value, show a note when it does not fit, offer a calendar or clock for dates and times, and tidy it on Return (1,25,000, 14 February 2027, 98765 43210). A value that does not fit is never used: the app falls back to the last or ready value, so it still never stops.
- **Currency keeps its commas but still counts.** Inside a formula, 1,25,000 is read as 125000, so it multiplies and adds.
- **Say the type by voice too.** Phone digits ("nine eight seven..."), amounts ("2 lakh"), dates ("14th of February"), emails ("name at example dot com") are turned into the right value.
- **Formulas without brackets.** Say "days to event date", "today plus 7", "price times quantity" or "sum of price and tax" and the formula is built, with variable names matched for you.
