# KeyDo 3.87

## Prompt Builder: compact and temporary link up front
- The temporary link box now sits at the top of Prompt Builder with a bold border, instead of at the bottom. Paste a link, Send to link, Clear (or say "clear link").
- Compact layout for a browser panel of about a third of the screen: the page drops to one column when it is narrow, the step bar hides when there is no room, and the header, cards and spacing are smaller. Voice commands and Copy are icons.
- Collection Builder shares the same slimmer header and cards.

## Keyboard safety
Checked: this version only changes layout. The key tap, its release guard and the heartbeat watchdog were not touched, and nothing new swallows keys.
