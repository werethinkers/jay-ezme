Matching app pages, cover crop, and removable files

- AppBuilder home: app covers now play videos and GIFs and show pictures, like WishStudio. Use "Crop and position" in an app's cover menu to choose what part shows, with top, middle or bottom, sliders and zoom.
- WishStudio and AppBuilder now share the same card, tab and icon look. Wish apps use the same clear icons and warm colours as AppBuilder apps.
- Media Resizer and Video Cutter: "From shortcut" adds the media of any saved shortcut as new files to edit.
- Both tools: each added file has a remove button. It only takes the file out of the editor and never deletes the original.
