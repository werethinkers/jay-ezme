# KeyDo 4.47

**Browser in its own window**
- New **Open the browser in its own window** button in the Browser top bar, and **File > New Browser Window** (Shift Command N).
- Every window has its own tabs, selected tab, split view and web pages, so you can browse different things side by side and swipe between windows. Sign-ins are shared with the main browser.
- A separate window does not save its tabs: closing it closes them. The main browser keeps saving as before.

**One voice at a time**
- The mic under the prompt, the other Speak buttons, the Hey KeyDo voice bubble and Fill by voice no longer run together. Starting one stops the others, and the Hey KeyDo listener comes back when the mic is free again.

**Keyboard safety:** checked. The key tap, popup and every mode that swallows keys are untouched. The voice change only starts and stops listeners.
