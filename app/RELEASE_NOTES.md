# KeyDo 4.14

## Collection preview: rename changes the shortcut too
- As soon as you save a new file name (typing or by voice), the display name **and the shortcut** change together. The shortcut becomes the full file name in the collection's own prefix or suffix pattern, for example \sunset-beach.media.
- The suggestions under the name refresh to match the new name. If you prefer the short one, or your own, tap it or say "short shortcut". Everything is applied when you close the preview.

## Keyboard safety
Checked. The key tap, popup key handling, voice and key-swallowing modes were not touched.
